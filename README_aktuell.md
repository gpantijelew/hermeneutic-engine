# Hermeneutic Engine

Multi-source RAG system with guaranteed fairness for multilingual corpora.

**Version:** v50.5 "Hermeneutic Fairness"  
**Status:** Research Prototype

## 🎯 Key Innovation

Ensures **every** user-selected source appears equally in synthesis—regardless of language, length, or embedding quality.

**Test Result:** 100% coverage (5 docs, 4 languages) vs. 40% baseline.

## 🚀 Quick Start
```bash
pip install -r requirements.txt
streamlit run app.py
```
